## Что это за проект
Persistent multiplayer world engine.
Telegram — только интерфейс.
AI — только интерфейс/помощник, не источник истины.
Один Telegram-чат = один независимый WORLD INSTANCE.

## Нельзя нарушать
1. Не смешивать данные разных WORLD INSTANCE.
2. AI не меняет каноническое состояние напрямую.
3. Telegram не содержит игровой логики.
4. База данных не является игровым движком.
5. Все значимые изменения идут через EVENTS.
6. Player knowledge ≠ world truth.
7. NPC knowledge ограничено.
8. Не создавать God Object / GameManager.
9. Не переписывать архитектуру ради одной функции.
10. Если есть конфликт с архитектурой — остановись и объясни.

## Рабочий процесс
Перед любой большой задачей:
1. Прочитай нужные документы.
2. Посмотри существующий код.
3. Предложи план: какие файлы будут затронуты.
4. Дождись подтверждения.
5. Реализуй маленькими шагами.
6. Добавь тесты на важные переходы состояния.
7. Сделай git commit.

Никогда не делай сразу «всю игру». Только один вертикальный срез за раз.
